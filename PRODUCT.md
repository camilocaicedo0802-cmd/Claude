## Platform

web

## Stack

Next.js (App Router, static export) + React + TypeScript + Tailwind CSS v4 + Motion for React + Lenis + Lucide icons, as requested in the brief. npm workspaces monorepo: two apps (`apps/editor`, `apps/disenador`) sharing one component/content package (`packages/core`). GSAP was considered and left out: every interaction in the brief is covered by Motion's scroll and layout APIs, so a second animation runtime would only add weight.

## Users

Potential clients evaluating whether to hire Juan Camilo Caicedo: brands, personal-brand creators, marketing agencies and companies that need video editing, motion graphics and social content. They arrive from a WhatsApp/Instagram link or a search, usually on a phone, and decide in seconds whether the work looks professional enough to start a conversation.

## Product Principles

1. The work leads. Real videos are visible from the first second; the interface recedes.
2. Every number on the page is a number from his own screenshots, with its context.
3. One action: WhatsApp. Everything else supports that decision.
4. Motion has intent: it shows editing craft (cuts, masks, timing), never decoration for its own sake.
5. Easy to maintain: adding a project is editing one typed data file.

## Accessibility & Inclusion

WCAG AA contrast on all UI text, `prefers-reduced-motion` respected everywhere, keyboard-operable players and modals, touch alternatives to every hover interaction, captions/labels on media controls.
